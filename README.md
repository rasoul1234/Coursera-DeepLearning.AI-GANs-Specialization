# Coursera-DeepLearning.AI-GANs-Specialization
The DeepLearning.AI GANs Specialization is a three-course intermediate program that teaches you how to build, optimize, and deploy Generative Adversarial Networks using PyTorch. You will hands-on implement architectures like StyleGAN, CycleGAN, and Pix2Pix for tasks like image-to-image translation and data synthesis.
